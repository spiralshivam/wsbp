Project details

Problem: explore whether station-month behaviour forms stable, interpretable groups that can support data-quality assessment.

Scope: eight large-city US stations and six years of data. The sample is intentionally small and should not be treated as globally representative.

Team: Shivam Misser and Rishit Bajaj · INT396 CA Project · Section K3P24RD.

Data and preprocessing details

Raw data uses NOAA tenths-of-units; temperature and precipitation are converted to °C and mm. NOAA missing values (−9999) and quality-flagged readings are dropped. Measurement/source flags alone do not invalidate a reading.

Coverage is the fraction of eligible TMAX, TMIN and PRCP measurements observed during a month. Missing feature cells are median-imputed later in the modeling pipeline.

To refresh source files, run python src/run_analysis.py --download (internet required). The standard app/API run reads data/processed/station_month_profiles.csv.

Feature preparation details

Precipitation is log-transformed to reduce the influence of very wet months. Month number is encoded with sine and cosine so that seasonal proximity is represented continuously across the year boundary.

Before clustering, the feature matrix is median-imputed and standardised to z-scores. This prevents features measured on larger numerical scales from dominating distance calculations.

Model fitting details

Partition models are fitted for candidate cluster counts k = 2, 3, 4 and 5 by default; k = 6 is also supported. K-Means uses multiple initialisations with a fixed random seed. k-medians selects the lowest L1 objective across random starts.

Hierarchical methods are comparison baselines; Ward linkage is only defined for Euclidean distance. PCA is fitted after standardisation for the two-dimensional display, not for clustering.

MODULE 04

Validation

Multiple measures help assess separation, compactness, stability and agreement.

05 / 07
✓
In brief

No single metric determines quality. The selection rule considers group size, silhouette, resampling stability and Davies–Bouldin score.

SEPARATION

Silhouette

Compares within-cluster closeness with separation from the nearest other cluster. Higher is better.

COMPACTNESS

Davies–Bouldin

Measures within-group spread relative to between-group separation. Lower is better.

STABILITY

Subsample ARI

Refits on repeated 80% subsamples and compares labels with Adjusted Rand Index.

OBJECTIVE

WCSS / L1

Reports the model’s fitting objective. WCSS and L1 values are not directly comparable.

MODEL SELECTION RULE
Drop groups under 5%→Keep silhouette within 0.02 of best→Prefer stability, then lower DB
Validation details and interpretation

Subsample stability is computed over 20 repeated 80% draws using adjusted Rand index between the full-data partition and each refit on the same sampled rows. This assesses sensitivity to sampling variation, not truth or real-world fault detection accuracy.

Silhouette is calculated with the model’s matching distance. Davies–Bouldin uses Euclidean geometry. WCSS is the K-Means sum of squared distances; the k-medians L1 objective is a different quantity.

How to read these results

Cluster labels are arbitrary identifiers. Compare the group summaries and metrics to understand the partition. The PCA view can hide differences because it compresses seven dimensions into two.

These results describe observed climate and seasonal patterns in a small sample. They do not establish that a station is faulty or rank station operators.
